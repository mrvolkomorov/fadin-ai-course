Приложение 5

★ Опция: LM Studio на Apple Silicon

Это не основной способ — для редких случаев, когда у вас есть мощный Apple Silicon MacBook (M1/M2/M3/M4 с 16+ GB unified memory). Используется для работы офлайн: в самолёте, в поезде, на объекте без интернета.

  1. Установить LM Studio: brew install --cask lm-studio или скачать с lmstudio.ai.
  2. Вкладка «Discover» → найти «Qwen 2.5 7B Instruct» → скачать (~4.7 GB).
  3. Вкладка «Chat» — выбрать модель — задать вопрос.
  4. Вкладка «Developer» → включить «Running LM Studio on this machine».
  5. API endpoint: http://localhost:1234/v1 (OpenAI-совместимый).
  6. В LobeHub / n8n: указать Base URL = http://localhost:1234/v1.

Минимальные требования: Apple M1/M2/M3/M4 с 16 GB unified memory, macOS 13+.

Приложение 6

Облачные решения в один клик и ручное развертывание

Для запуска Ollama с обезличивателем у вас есть три пути. Начните с №1а (Yandex Cloud) — самый быстрый. Переходите к №2 (Reg.ru ручная), если нужна ручная установка и полный контроль.

№1а. Yandex Cloud Marketplace — в один клик (рекомендуется)

Yandex Cloud опубликовал готовый продукт «Ollama + WebUI» в своём маркетплейсе. Разворачивается за 5 минут без знания Docker, SSH или Linux — просто выбираете модель при создании ВМ.

  1. Зарегистрироваться на yandex.cloud (платёжный аккаунт + пробный период 60 дней).
  2. «Compute Cloud» → «Создать ВМ» → вкладка «Marketplace» → выбрать «Ollama + WebUI».
  3. В поле «Конфигурация продукта» указать модель (например, qwen2.5:14b-instruct или deepseek-r1:8b) — она загрузится автоматически.
  4. Выбрать конфигурацию (минимум 8 vCPU / 16 GB RAM для Qwen 14B; 4 vCPU / 8 GB для Qwen 7B).
  5. Указать SSH-ключ и группу безопасности с открытым TCP/22.
  6. Нажать «Создать ВМ» — через 5 минут ВМ готова.
  7. Подключиться к веб-интерфейсу: ssh -L 8080:localhost:8080 user@ip → открыть http://localhost:8080 в браузере.
Преимущества: оплата российскими картами (СБП, ЮMoney); данные физически находятся в российском ЦОД; готовый веб-интерфейс Open WebUI; можно выбрать пресет модели при установке.
Стоимость: минимальный тариф ВМ (4 vCPU / 8 GB / 40 GB NVMe) ≈ 1,5–3 ₽/час ≈ ~1000–2000 ₽/мес при круглосуточной работе. Архивирование ВМ — оплата прекращается.

№1б. Ollama Cloud — без своего сервера ($20/мес)

Официальный облачный сервис Ollama (ollama.com/cloud). Подходит, если не хотите возиться с серверами вообще.

  • Free — $0, базовые кредиты, 1 модель одновременно.
  • Pro — $20/мес или $200/год, $60 кредитов/мес, 3 модели параллельно.
  • Max — $100/мес, $300 кредитов, 10 моделей параллельно.
  • Team — $500/мес, общий пул для команды.

Как подключить к LobeHub / n8n: открыть ollama.com → зарегистрироваться → API keys → создать ключ → в LobeHub / n8n указать Base URL = https://ollama.com, вставить API Key.

Важно: данные уходят на серверы Ollama. Для «жёлтой» корзины — приемлемо (нет хранения, ZDR-политика по умолчанию). Для «красной» — только локальное развертывание по №1а или №2.

№2. Reg.ru Cloud — ручная установка Ollama (если нужен полный контроль)

Этот путь остаётся для тех, кто хочет полную ручную настройку (другой регион, кастомные модели, интеграция с другим ПО на сервере). Reg.ru предоставляет преднастроенный образ «ИИ-ассистент на базе Ollama» — Ollama ставится автоматически, остаётся подключиться и загрузить свою модель.

  1. Войти на cloud.reg.ru → «Создать сервер» → регион Москва.
  2. В выборе ОС найти преднастроенный образ Ollama (если есть в маркетплейсе) — иначе выбрать Ubuntu 22.04 + Docker (пошаговая ручная установка ниже).
  3. ОС: Ubuntu 22.04 LTS, тариф 8 vCPU / 16 GB RAM / 100 GB NVMe.
  4. Включить чекбокс «Установить Docker» при создании (или готовый образ Ollama).
  5. После создания — скопировать IP-адрес и SSH-ключ из личного кабинета.
  6. Подключиться по SSH: ssh root@<ip>.
  7. Запустить Ollama в Docker (если ставили вручную):
    docker run -d -p 11434:11434 --name ollama \ -v ollama_data:/root/.ollama \ ollama/ollama
  8. Скачать модель Qwen 2.5 14B: docker exec ollama ollama pull qwen2.5:14b-instruct
  9. Открыть порт 11434 в файрволе Reg.ru: «Сеть» → «Firewall» → разрешить входящие на 11434.
  10. Проверить: curl http://<ip>:11434/api/tags → список моделей.
  11. В LobeHub / n8n: Base URL = http://<ip>:11434/v1.
  12. После работы — «Заархивировать сервер» в Reg.ru (оплата прекращается, состояние сохраняется).
Приложение 7

Универсальный промпт-обезличиватель

Работает во всех способах №1 (VPS Ollama) и №2 (облака). Меняется только «движок», который его выполняет.

Ты — обезличиватель документов для производственной компании. Твоя задача: превратить "жёлтые" данные в "зелёные", сохранив смысл и структуру. Правила замены (применяй строго): 1. ФИО людей — на [ФАМИЛИЯ_ИМЯ_ОТЧЕСТВО_N], где N — порядковый номер с начала документа. 2. Названия организаций — на [ОРГАНИЗАЦИЯ_N] с сохранением формы собственности (ООО/ЗАО/ИП). 3. ИНН/ОГРН/КПП/СНИЛС — на [ИНН]/[ОГРН]/[КПП]/[СНИЛС]. 4. Паспортные данные — на [ПАСПОРТ]. 5. Телефоны, email, адреса — на [ТЕЛЕФОН]/[EMAIL]/[АДРЕС]. 6. Номера договоров, счетов, заказов — на [ДОГОВОР_N]/[СЧЁТ_N]/[ЗАКАЗ_N]. 7. Суммы в рублях — оставь как есть (это бизнес-данные). 8. Даты — оставь как есть. 9. Связки: если "Иванов из ООО «СМУ-7»" — замени ВСЕ элементы одной связки одинаковыми плейсхолдерами в обоих местах, чтобы связь сохранилась. Структура выдачи: Верни ТОЛЬКО обезличенный текст, без комментариев. Сохрани абзацы. Не добавляй пояснений типа "вот обезличенный текст". Документ: [ЗДЕСЬ ВСТАВЬТЕ ТЕКСТ]

Приложение 9

Промпт для производственных документов (КП, сметы, акты)

Ты — обезличиватель производственной документации. На входе — коммерческое предложение, смета, акт приёмки или договор подряда. Что заменять: - ФИО заказчика, подрядчика, представителей → [ФИО_N]. - Названия организаций (исполнитель, заказчик, субподрядчик) → [ОРГАНИЗАЦИЯ_N]. - ИНН/ОГРН/КПП → [ИНН]/[ОГРН]/[КПП]. - Юридические адреса → [АДРЕС]. - Банковские реквизиты (р/с, к/с, БИК) → [РЕКВИЗИТЫ]. - Номера договоров, смет, актов → [ДОГОВОР_N]/[СМЕТА_N]/[АКТ_N]. - Названия объектов (если содержат адрес или имя собственника) → [ОБЪЕКТ_N]. Что НЕ заменять: - Суммы, единицы измерения (м², м³, шт). - Названия работ и материалов ("бетонирование фундамента, М300"). - Технические характеристики. - Даты. Связки: если в одной строке ФИО + организация + объект + сумма, все подлежащие замене элементы превращаются в плейсхолдеры с одинаковыми индексами N, чтобы связь сохранилась. Приложение 12

Чек-лист безопасности на входе узла

  • Документ проверен против 3 корзин (Приложение 1) — уровень чувствительности определён.
  • Если «красный» — обезличивание НЕ спасает, документ остаётся локально на VPS, никогда не покидает контур.
  • Если «жёлтый» — обезличиватель запущен ДО отправки в облако.
  • Промпт-обезличиватель — единый, версия от 13.10.2026, в переменной окружения n8n.
  • Решение «куда отдавать после обезличивания»:
    • Локальный VPS-контур (способ №1) → можно сразу в любой ИИ
    • Российское облако (Yandex/GigaChat/AiTunnel, способ №2) → допустимо
    • Зарубежное облако (ChatGPT/Claude) → после обезличивания + доп. проверка связок человеком
  • Каждый месяц — аудит: % документов, прошедших через обезличиватель.
  • Ключ от VPS — в менеджере паролей, не в коде n8n.
  • При смене сотрудника — передача ключей + смена пароля VPS.
  • Документы, отправленные в облако после обезличивания, — логируются (для аудита).
  • При архивировании VPS — данные на диске шифруются (LUKS или провайдерский шифрованный диск).
Приложение 13

Дорожная карта внедрения обезличивателя (14 дней)

  1. День 1: Зарегистрироваться на Yandex Cloud (cloud.yandex.ru) — пробный 60-дневный период. Оплатить 200 ₽ для теста.
  2. День 2–3: В Compute Cloud → Marketplace → выбрать «Ollama + WebUI». При создании ВМ указать модель qwen2.5:14b-instruct или deepseek-r1:8b. Через 5 минут обезличиватель работает через веб-интерфейс. Прогнать 5 своих реальных документов.
  3. День 4–5: Если Yandex Cloud не подходит — альтернатива: Ollama Cloud ($20/мес, без своего сервера). Зарегистрироваться на ollama.com → API key → подключить к LobeHub / n8n (Base URL = https://ollama.com).
  4. День 6–8: Если нужен полный контроль — арендовать VPS в Reg.ru Cloud. Поднять Ollama в Docker, скачать Qwen 2.5 14B. Подключить к LobeHub как «OpenAI-совместимый поставщик».
  5. День 9–11: Создать служебного агента «Обезличиватель» в LobeHub (через любой из выбранных способов). Проверить на тестовом документе из вашей работы.
  6. День 12–14: Встроить обезличиватель в n8n-конвейер «совещание → протокол» (или в ваш рабочий сценарий). Проверить end-to-end. Архивировать VPS, если использовали.
